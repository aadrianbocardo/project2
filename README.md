## Setup

Use Python 3.14 and create a virtual environment in the project folder:

```sh
python3 -m venv project2_env
```

Activate it on macOS or Linux with `source project2_env/bin/activate`, or on Windows with `project2_env\Scripts\activate`. Then install the dependencies:

```sh
python -m pip install -r requirements.txt
```

Open `scripts/Thirumurugan_Bocardo_part1_comics.ipynb` in VS Code or Jupyter and select the new environment as the notebook kernel. Run the notebook with `scripts/` as its working directory: its dataset and report paths use `../datasets/` and `../outputs/`.
